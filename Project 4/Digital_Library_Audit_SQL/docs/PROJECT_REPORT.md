# Digital Library Audit — Project Report

## Introduction
The Digital Library Audit database organizes books, students, and issue records and provides SQL reports for library operations.

## Objectives
- Create related Books, Students, and IssuedBooks tables.
- Find overdue unreturned books.
- Calculate category popularity.
- Identify inactive students.
- Demonstrate safe cleanup by previewing records before deletion.

## SQL Concepts
CREATE TABLE, constraints, indexes, joins, WHERE, IS NULL, COUNT, GROUP BY, ORDER BY, HAVING, MAX, NOT EXISTS, DELETE, and date intervals.

## Conclusion
The project demonstrates how a relational database can support routine library auditing and data cleanup.
