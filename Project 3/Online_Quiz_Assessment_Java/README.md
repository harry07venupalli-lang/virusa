# Online Quiz & Assessment System

Core Java console application for taking timed multiple-choice quizzes and managing questions.

## Features
- Multiple-choice quiz
- 60-second total timer
- Automatic scoring
- Correct, wrong, and unanswered counts
- Percentage and performance analysis
- File-based question bank
- Admin question creation
- Java test class

## Run

javac -d out src/*.java
java -cp out QuizApp

Test with:

java -cp out QuizServiceTest
