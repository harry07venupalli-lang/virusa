# Online Quiz & Assessment System — Project Report

## Introduction
This Java console application provides a simple online assessment workflow using object-oriented programming and file-based question storage.

## Objectives
- Present MCQ questions to a user.
- Enforce a total 60-second quiz limit.
- Automatically calculate score and percentage.
- Report correct, wrong, and unanswered questions.
- Allow an administrator to add questions.

## Technologies
Java, OOP, collections, file I/O, Scanner, and basic testing.

## Main Classes
Question stores question data. QuestionBank loads and saves questions. QuizService evaluates answers. QuizResult stores results. AdminService validates new questions. QuizApp provides the console interface.

## Testing
QuizServiceTest verifies answer evaluation and result counts.
