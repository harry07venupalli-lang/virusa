# Online Retail Sales Analysis Database — Project Report

## Introduction
A PostgreSQL-compatible relational database for an online retail store. It stores customers, products, orders, and order items and provides analytical SQL queries.

## Objectives
- Design a relational schema with primary and foreign keys.
- Store retail transaction data.
- Analyze products, customers, monthly revenue, and categories.
- Identify inactive customers.
- Demonstrate joins, aggregation, CTEs, window functions, and indexes.

## Key Analysis
Top-selling products, most valuable customers, monthly revenue, category-wise revenue, inactive customers, spending rank, average order value, highest-revenue month, product performance, customers without orders, and monthly revenue growth.

## Technologies
SQL and PostgreSQL-compatible syntax.

## Conclusion
The project demonstrates practical relational database design and SQL-based business analysis.
