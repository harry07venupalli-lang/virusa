# FareCalc Travel Optimizer

Core Python ride-fare calculator.

## Requirements
- Economy 10, Premium 18, SUV 25 per km
- Peak hours 17:00 through 20:00
- 1.5x surge multiplier during peak hours
- calculate_fare(km, vehicle_type, hour)
- Invalid vehicle type: Service Not Available
- Input validation and formatted receipt

## Run

python FareCalc.py
